Desktop TimeStretch Player with playlist support

A standalone desktop version inspired by 29a.ch/timestretch. Load single tracks or whole folders and play them sequentially with stretch, pitch, and volume controls — no browser required.

Download / View on GitHub

Source code is available now. Build the Windows EXE yourself with the steps below, or check Releases for pre-built files when available.

Features

  • Similar UI and feel to the original TimeStretch player
  • Open a single track or an entire folder as a playlist
  • Sequential playback of songs from a folder
  • Stretch, Pitch, Tune, and Volume controls
  • Runs as a native Windows EXE (Electron)

Build the EXE

  1. Clone the repo and open a terminal in the folder
  2. Install dependencies: npm install
  3. Run in development: npm start
  4. Build the installer: npm run dist

The built EXE will appear in the dist/ folder.

Current stretch uses playbackRate (affects pitch). True independent time-stretching can be added later with a library such as SoundTouch.
